Fuel level now reads in calibrated gallons and ECU data logs to pandas-ready CSV files.

## What's new

### Fuel-level calibration
- Convert the fuel-sender voltage into calibrated gallons for the installed tank.
- Make the fuel-level graph follow the gauge's selected unit.
- Add low-pass filtering and unit-aware Y-axis scaling to the fuel graph.

### Separate monitored ECU logs
- Keep human-readable app diagnostics in `app_logs.txt`.
- Write monitored ECU values as wide, pandas-ready CSV files.
- Start a new timestamped CSV whenever the monitored parameter list or units change.
- Store one complete ECU response per row, with units included in column headings.
