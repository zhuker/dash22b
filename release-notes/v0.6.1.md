Installs over earlier test builds again: the version code now comes from the release tag, so a release always outranks the builds before it.

## What's new

This is v0.6.0 with one fix. Nothing in the app itself changed.

### Fix
- **v0.6.0 would not install over the fast-poll test build.** Android reported "package
  appears to be invalid", which is how it reports a version downgrade. The versionCode was
  the total commit count, and squash-merging the `gps` and `ssm-fastpoll` branches left
  `main` with fewer commits (62) than the branch build already on the phone (64).
- **The versionCode now comes from the tag:**
  `major*100_000_000 + minor*1_000_000 + patch*10_000 + commits since the tag`. This
  release is 6,010,000. A release now outranks every build made before its tag, however
  the branches were merged, so it installs over any earlier build as a normal update and
  keeps the app's data: odometer, presets, settings.
